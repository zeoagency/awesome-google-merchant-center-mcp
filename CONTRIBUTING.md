# Contributing to Awesome Google Merchant Center MCP

This list collects MCP servers, CLIs, and SDKs with implemented Google Merchant Center support. Read [AGENTS.md](./AGENTS.md) for the inclusion, verification, and formatting rules.

## Pull request checklist

- [ ] Link to the tool's canonical repository, package, or official service documentation.
- [ ] Verify actual Merchant Center functionality in source code or official service documentation.
- [ ] Check that its API version remains supported and its documented setup is usable.
- [ ] Describe only verified Merchant Center functionality in one or two factual sentences.
- [ ] Add the entry to the appropriate MCP, CLI, or SDK section and update its counts.
- [ ] Check URLs and navigation links.
- [ ] Run `npx --yes markdownlint-cli2@latest "**/*.md"`.
